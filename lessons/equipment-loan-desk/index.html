Borrowing Equipment and Managing Time at Work

Workplace English · B1 (estimated)

Learners will understand and correctly use check out and run late in workplace contexts.

Open exercises in HọcTA

Reading

Teams using the training rooms can check out a portable projector from the equipment desk. Before leaving, write the serial number and team name on the checkout sheet so staff can track each loan. The projector is due back by 5 p.m. on the same day, even if a meeting ends early. Keep it in the padded case and return the charger with the device. If a session is likely to run late, call the desk before 4 p.m. to request an extension. Staff will confirm the new return time by email. Equipment left in a room after closing is treated as unreturned until the desk records it, so teams should allow a few minutes to complete the handover.
