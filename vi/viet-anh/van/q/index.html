Từ điển Việt–Anh vần Q (16 mục từ)

Chọn mục từ tiếng Việt bắt đầu bằng chữ Q để so sánh các từ và cụm từ tiếng Anh tương ứng theo trình độ CEFR, IELTS Core và Học thuật AWL. Hoặc quay lại ô tìm kiếm Việt–Anh.

A Ă Â B C D Đ E Ê G H I K L M N O Ô Ơ P Q R S T U Ư V X Y
  • quả cầu → ball, sphere, globe
  • quá chừng → terribly, unfair, unreasonable
  • quả quyết → assurance, assure, protest (+4)
  • quán ăn → pub, restaurant, coffee shop (+1)
  • quan điểm → notion, attitude, opinion
  • quản lý → administration, manage, controlling (+1)
  • quan sát → survey, observation, see (+1)
  • quan tâm → consideration, interest, concerned
  • quan trọng → significant, importance, serious (+3)
  • quần áo → dress, clothes, costume (+2)
  • quấy rầy → bother, disturb, worry (+5)
  • quyền lực → authority, control, lordship
  • quyến rũ → attractive, catching, fascinating (+3)
  • quyền thế → authority, importance, lordship
  • quyết định → crucial, decide, decision (+3)
  • quyết tâm → resolution, determine, resolve (+1)
