Ghi chú sử dụng

Điểm cần nhớ

  • skill = kỹ năng (đếm được): language skills (kỹ năng ngôn ngữ); a skill FOR/AT something: "a skill for negotiation" (tài đàm phán);
  • skilled = lành nghề: "a skilled worker" (thợ lành); skillful = khéo léo;
  • soft skills vs hard skills = kỹ năng mềm/cứng (tuyển dụng chuẩn).

Dễ nhầm

  • skill (kỹ năng luyện được) vs talent (tài thiên bẩm) vs ability (khả năng bao trùm).

Mẫu câu giá trị

  • "Listening is a skill you can train daily." (nghe là kỹ năng luyện được mỗi ngày).
  • "Employers value skilled communicators." (nhà tuyển dụng chuộng người giao tiếp giỏi).
