Ghi chú sử dụng

Điểm cần nhớ

  • build — built, built (bất quy tắc): xây/dựng: "build a house"; build MỞ RỘNG: "build trust/confidence/muscle".

Dễ nhầm

  • build up = tích lũy/tăng dần: "build up savings"; build on = dựa trên nền: "build on past success".
  • building = tòa nhà (n); rebuild = xây lại.

Mẫu câu giá trị

  • "Reading builds vocabulary faster than memorizing lists." (đọc giúp tích lũy từ).
  • "The city built two new hospitals last year." (xây hai bệnh viện mới).
