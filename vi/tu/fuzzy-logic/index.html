Nghĩa tiếng Việt của

fuzzy logic

Cụm từnoun phrase (uncountable; computing)Biên soạn riêngIELTS

1. logic mờ, hệ logic xử lý các mức độ thay vì chỉ đúng/sai tuyệt đối

Cấu trúc: fuzzy-logic system · apply fuzzy logic to · fuzzy logic controls

The washing machine uses fuzzy logic to adjust the cycle.

Máy giặt dùng logic mờ để điều chỉnh chu trình.

Fuzzy logic can represent a temperature as warm rather than simply on or off.

Logic mờ có thể biểu diễn nhiệt độ là ấm thay vì chỉ bật hoặc tắt.

Lưu ý: Fuzzy logic là hệ logic cho phép mức độ đúng sai nằm trên một thang liên tục thay vì chỉ 0 hoặc 1, giúp mô hình hóa các khái niệm mơ hồ như hơi nóng hay khá bẩn. Đây là cách xử lý thông tin không chính xác, không có nghĩa hệ thống đưa ra kết quả tùy tiện.

noun

  1. a form of mathematical logic in which truth can assume a continuum of values between 0 and 1
