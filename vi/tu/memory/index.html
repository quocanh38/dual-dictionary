Ghi chú sử dụng

Điểm cần nhớ

  • memory = trí nhớ/kỷ niệm (n): from memory = từ trí nhớ ("play from memory" — diễn không nhìn nhạc); in memory OF = tưởng niệm;
  • memorize (v) = học thuộc: memorize collocations (thuộc collocations); memorable = đáng nhớ;
  • memory = bộ nhớ máy (RAM/storage): low on memory (hết bộ nhớ).

Dễ nhầm

  • memory (trí nhớ khả năng/kỷ niệm) vs remembrance (sự tưởng niệm trang trọng) vs recall (khả năng gợi lại — thuật ngữ học từ!).

Mẫu câu giá trị

  • "Spaced review moves words into long-term memory." (ôn giãn cách đẩy từ vào trí nhớ dài hạn — nguyên lý app!).
  • "The trip left a fond memory." (chuyến đi để lại kỷ niệm đẹp).
