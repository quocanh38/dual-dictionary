Ghi chú sử dụng

Điểm cần nhớ

  • true = đúng sự thật/chân thành: "a true story" (chuyện có thật), "a true friend" (bạn chân thành).
  • come true = thành hiện thực: "Dreams come true."
  • truly = thật lòng: "Yours truly" (kết thư).

Dễ nhầm

  • true (đúng với sự thật) vs real (tồn tại thật, không giả): "a real diamond" (kim cương thật) / "a true story" (chuyện đúng sự thật).

Mẫu câu giá trị

  • "Is the rumor true?" (tin đồn có thật không?).
  • "Her help made my dream come true." (sự giúp đỡ của cô biến giấc mơ thành thật).
