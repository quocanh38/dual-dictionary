Ghi chú sử dụng

Điểm cần nhớ

  • the same (as) = giống hệt: "My bag is the same as yours" (bắt buộc có the).
  • the same + danh từ: "the same train" (cùng chuyến); at the same time = cùng lúc / tuy nhiên.

Dễ nhầm

  • the same ≠ similar: same hệt nhau; similar giống mà không hệt.

Mẫu câu giá trị

  • "We went to the same school." (chúng tôi học chung một trường).
  • "Prices stayed the same for a year." (giá giữ nguyên cả năm).
