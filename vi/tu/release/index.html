Ghi chú sử dụng

Điểm cần nhớ

  • release = phát hành/thả (v/n): release a product/update (phát hành bản mới — "the new release" — bản phát hành); release a prisoner = tha tù;
  • press release = thông cáo báo chí; release date = ngày ra mắt;
  • release = xả/thư giãn: "release stress" (xả stress).

Dễ nhầm

  • release (phát hành chính thức) vs launch (ra mắt sự kiện thị trường) vs roll out (triển khai dần từng phần).

Mẫu câu giá trị

  • "The update releases tomorrow." (bản cập nhật ra mắt ngày mai — đúng ngôn ngữ dev!).
  • "Exercise helps release stress." (vận động giúp xả stress).
