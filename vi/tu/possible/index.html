Ghi chú sử dụng

Điểm cần nhớ

  • possible = có thể xảy ra: "It is possible TO finish early" (khuôn it is possible to V).
  • as soon as possible = sớm nhất có thể.
  • possible vs probable/likely: possible = có thể (chưa chắc); probable/likely = khả năng cao.

Dễ nhầm

  • It is possible FOR somebody to do: "It is possible for beginners to improve fast." (người mới hoàn toàn có thể tiến bộ nhanh).

Mẫu câu giá trị

  • "Remote work makes it possible to live anywhere." (việc từ xa khiến sống đâu cũng được).
  • "Send the file as soon as possible." (gửi file sớm nhất có thể).
