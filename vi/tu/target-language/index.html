Nghĩa tiếng Việt của

target language

Cụm từnoun phrase (countable, linguistics)Biên soạn riêngPhổ biếnIELTS

1. ngôn ngữ đích, ngôn ngữ mà văn bản được dịch sang

Cấu trúc: translate a text into the target language · a target-language version · from the source language to the target language

The translator checked whether the joke worked in the target language.

Dịch giả kiểm tra xem câu đùa có hiệu quả trong ngôn ngữ đích hay không.

The report was translated from Korean into the target language, English.

Báo cáo được dịch từ tiếng Hàn sang ngôn ngữ đích là tiếng Anh.

2. ngôn ngữ mà một người đang học như ngoại ngữ hoặc ngôn ngữ thứ hai

Cấu trúc: learn/practise the target language · exposure to the target language · use the target language in class

Learners improve faster when they hear the target language outside the classroom.

Người học tiến bộ nhanh hơn khi nghe ngôn ngữ mình đang học ở ngoài lớp.

The teacher encouraged students to use the target language during pair work.

Giáo viên khuyến khích học sinh dùng ngôn ngữ đích khi làm việc theo cặp.

Lưu ý: Target language là ngôn ngữ đích: ngôn ngữ mà văn bản được dịch sang hoặc ngôn ngữ người học đang học. Trong dịch thuật, source language là ngôn ngữ nguồn của bản gốc; vì vậy target language không phải ngôn ngữ xuất phát.

Định nghĩa tiếng Anh (WordNet 3.1)

noun

  1. the language into which a text written in another language is to be translated (Synonyms: object language)
  2. a computer language into which something written in another computer language is to be translated (Synonyms: object language)
