run by

Cụm từphrasal verbBiên soạn riêngPhổ biến

1. nói qua cho ai nghe để xin ý kiến

Cấu trúc: run something by/past somebody

Let me run the plan by my manager first.

Để mình trình kế hoạch qua quản lý trước đã.

Run that by me again — I didn't catch it.

Nói lại giúp mình lần nữa — mình chưa nghe rõ.

Lưu ý: 'Run something past somebody' cũng đúng — thông dụng trong công việc hằng ngày.
