Ghi chú sử dụng

Điểm cần nhớ

  • test = bài kiểm tra (n) / kiểm tra (v): "test a theory"; take a test = làm bài kiểm tra (take, không make).
  • test drive = chạy thử xe; blood test = xét nghiệm máu.

Dễ nhầm

  • test vs exam vs quiz: test kiểm tra định kỳ nhỏ; exam kỳ thi lớn; quiz trắc nghiệm nhanh.

Mẫu câu giá trị

  • "Scientists tested the vaccine on volunteers." (thử nghiệm vaccine trên tình nguyện viên).
  • "Practice tests build exam confidence." (đề luyện tạo tự tin khi thi).
