Ghi chú sử dụng

Điểm cần nhớ

  • return = quay lại/trả lại: "return home" (về nhà — KHÔNG "return back" ✗, return đã chứa nghĩa back!), "return a product" (trả hàng).
  • in return (for) = đổi lại: "help without expecting anything in return".

Dễ nhầm

  • return ticket = vé khứ hồi (BrE; AmE: round trip); return on investment = lợi tức đầu tư.

Mẫu câu giá trị

  • "He returned the borrowed books yesterday." (đã trả sách mượn hôm qua).
  • "She gave a lot and asked for nothing in return." (cho nhiều chẳng đòi đổi lại).
