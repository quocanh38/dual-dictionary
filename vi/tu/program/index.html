Ghi chú sử dụng

Điểm cần nhớ

  • program = chương trình (khóa học/tV/ứng dụng): "a training program". BrE cũng viết programme (TV/hội nghị).

Dễ nhầm

  • program (v) = lập trình: "program a robot"; programming = lập trình.
  • government programs = các chương trình của nhà nước (chủ đề xã hội).

Mẫu câu giá trị

  • "She joined a leadership program for women." (chương trình lãnh đạo).
  • "The software was programmed in Python." (được lập trình bằng Python).
