Ghi chú sử dụng

Điểm cần nhớ

  • friend = bạn — make friends WITH somebody = kết bạn với ai (friends luôn số nhiều trong cụm này: "make friend" ✗).

Dễ nhầm

  • close friend = bạn thân; mutual friend = bạn chung; friendly = thân thiện (tính chất, không phải "đang là bạn").
  • friendship = tình bạn; befriend = kết bạn với (văn viết).

Mẫu câu giá trị

  • "She is easy to talk to, so she makes friends quickly." (dễ kết bạn).
  • "A friend in need is a friend indeed." (hoạn nạn mới biết bạn hiền).
