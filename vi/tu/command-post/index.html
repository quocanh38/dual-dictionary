command post

Cụm từnoun phrasedanh từBiên soạn riêngPhổ biến

1. chỉ huy sở (nơi điều hành tác chiến); (bóng) trung tâm điều hành mọi việc

Cấu trúc: set up a command post · run the rescue from a command post

The army set up a command post near the flood zone.

Quân đội lập chỉ huy sở gần vùng lũ.

Her kitchen became the command post for the party.

Nhà bếp cô hóa thành 'chỉ huy sở' của bữa tiệc.

Lưu ý: Nghĩa gốc quân sự; nghĩa bóng dùng cho phòng khủng hoảng, nơi chỉ đạo sự kiện.
