Ghi chú sử dụng

Điểm cần nhớ

  • Động từ: request + danh từ (trang trọng, KHÔNG "request for"): "request further information".
  • request that + S + V nguyên mẫu (văn hình thức): "We request that all passengers remain seated."
  • Danh từ: a request for something: "a request for asylum"; at somebody's request = theo yêu cầu của ai.

Dễ nhầm

  • request trang trọng hơn ask for — hợp văn công văn, đơn từ; đời thường dùng ask.
  • "request something from somebody" (xin ai cái gì) — giới từ from/of.

Mẫu câu giá trị

  • "Guests are requested to check out by noon." (khách được yêu cầu trả phòng trước trưa).
  • "The committee approved our request for extra funding." (ủy ban chấp thuận yêu cầu thêm kinh phí).
