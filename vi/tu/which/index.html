Ghi chú sử dụng

Điểm cần nhớ

  • which hỏi CHỌN trong số cụ thể: "Which one do you want?" — what hỏi mở.

Dễ nhầm

  • which nối mệnh đề quan hệ cho VẬT: "the book which I bought". Sau dấu phẩy chỉ dùng which, không that: "My car, which is old, still runs."
  • which thay cả mệnh đề: "He quit, which surprised everyone."

Mẫu câu giá trị

  • "Which option saves more time?" (lựa chọn nào tiết kiệm hơn).
  • "The policy, which took years to draft, finally passed." (chính sách ấy cuối cùng cũng thông qua).

Câu hỏi thường gặp
