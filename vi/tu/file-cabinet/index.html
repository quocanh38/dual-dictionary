Nghĩa tiếng Việt của

file cabinet

Cụm từnoun phrase (countable; North American English)Biên soạn riêngIELTS

1. tủ hồ sơ/tủ đựng tài liệu giấy (Bắc Mỹ)

Cấu trúc: a metal file cabinet · keep documents in a file cabinet · a file-cabinet drawer

She stored the signed contracts in a locked file cabinet.

Cô cất các hợp đồng đã ký trong tủ hồ sơ có khóa.

The file cabinet has four drawers for client records.

Tủ hồ sơ có bốn ngăn kéo đựng hồ sơ khách hàng.

Lưu ý: File cabinet là tủ văn phòng có ngăn/kệ để lưu hồ sơ giấy; tiếng Anh-Anh thường gọi filing cabinet. Cụm cũng dùng cho tủ hồ sơ máy tính theo nghĩa bóng, nhưng trong giao tiếp công nghệ nên nói file system hoặc folder nếu muốn chỉ cấu trúc lưu trữ số.
