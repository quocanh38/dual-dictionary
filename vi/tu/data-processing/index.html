Nghĩa tiếng Việt của

data processing

Cụm từnoun phrase (uncountable; computing)Biên soạn riêng

1. xử lý dữ liệu

Cấu trúc: data processing system · data-processing operations · process data for analysis

The software automates data processing for thousands of survey responses.

Phần mềm tự động xử lý dữ liệu cho hàng nghìn câu trả lời khảo sát.

Data processing converts the raw figures into a readable report.

Quá trình xử lý dữ liệu chuyển các số liệu thô thành báo cáo dễ đọc.

Lưu ý: Data processing là chuỗi thao tác trên dữ liệu để biến dữ liệu đầu vào thành kết quả có ích, thường do máy tính thực hiện. Nó có thể gồm thu thập, sắp xếp, tính toán, lưu trữ và xuất kết quả; không đồng nghĩa riêng với nhập dữ liệu (data entry) hay phân tích dữ liệu (data analysis).
