Ghi chú sử dụng

Điểm cần nhớ

  • state = bang / trạng thái / phát biểu (v): "the state of the economy" (tình trạng kinh tế), "The report states that..." (báo cáo nêu rằng — cụm trích dẫn Task 1).

Dễ nhầm

  • state-owned = nhà nước sở hữu; statement = tuyên bố/báo cáo tài chính.
  • state (v) nói dứt khoát, formal hơn say.

Mẫu câu giá trị

  • "The graph states nothing about causes." — nên dùng "shows"; state hợp cho văn bản chính thức: "The contract states..." (hợp đồng quy định).
  • "Switzerland is a wealthy state." (một quốc gia giàu có).
