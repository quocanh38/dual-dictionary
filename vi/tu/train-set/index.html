Nghĩa tiếng Việt của

train set

Cụm từnoun phrase (countable; chiefly British English)Biên soạn riêngPhổ biến

1. bộ tàu hỏa đồ chơi, thường gồm đoàn tàu và đường ray để lắp thành mô hình

Cấu trúc: an electric train set · assemble a train set · a model train set

He spent the afternoon assembling the train set on the living-room floor.

Cậu dành cả buổi chiều lắp bộ tàu hỏa đồ chơi trên sàn phòng khách.

The electric train set came with a station and several lengths of track.

Bộ tàu hỏa điện đi kèm một nhà ga và vài đoạn đường ray.

Lưu ý: Train set là bộ tàu hỏa đồ chơi gồm đầu máy và đường ray, đôi khi có thêm nhà ga hoặc toa xe; nhiều bộ có thể chạy bằng điện. Trong tiếng Anh Mỹ thường gọi là train set hoặc model train set tùy món đồ chơi cụ thể.
