Ghi chú sử dụng

Điểm cần nhớ

  • class = lớp học / tầng lớp / hạng: "business class" (hạng thương gia); class (buổi): "English class".
  • in class = trong giờ học; after class = sau giờ; classify = phân loại.

Dễ nhầm

  • class + động từ số ít (một lớp) hoặc số nhiều (từng người, BrE).

Mẫu câu giá trị

  • "There are twenty students in our class." (lớp mình có 20 bạn).
  • "The hotel offers first-class service." (khách sạn dịch vụ hạng nhất).
