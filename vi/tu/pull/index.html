Ghi chú sử dụng

Điểm cần nhớ

  • pull = kéo (v): pull somebody's leg = trêu ai chơi (không phải kéo chân!); pull over = cho xe dạt vào lề; pull through = vượt qua (bệnh/khủng hoảng);
  • pull (n) = sức kéo/sức hút: the pull of the sea (sức hút của biển);
  • pull out = rút lui/rút ra.

Dễ nhầm

  • pull (kéo về phía mình) vs push (đẩy xa mình) vs drag (kéo lê nặng nhọc).

Mẫu câu giá trị

  • "The app keeps pulling me back — in a good way." (app cứ kéo mình quay lại — theo nghĩa tích cực).
  • "The doctor says he will pull through." (bác sĩ nói anh sẽ qua cơn).
