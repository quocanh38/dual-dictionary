Ghi chú sử dụng

Điểm cần nhớ

  • message = tin nhắn/thông điệp (n) / nhắn (v): leave a message (để lại lời nhắn), send somebody a message (nhắn ai);
  • messaging = nhắn tin (messaging app); message = thông điệp ẩn: the film's message (thông điệp bộ phim);
  • messenger = người đưa tin/app Messenger.

Dễ nhầm

  • message (tin nhắn/thông điệp) vs note (ghi chú ngắn) vs text (SMS — động từ: "text me").

Mẫu câu giá trị

  • "I sent you a message with the details." (mình nhắn tin chi tiết cho bạn rồi).
  • "The message of the story is simple: keep going." (thông điệp truyện giản dị: cứ tiến lên).
