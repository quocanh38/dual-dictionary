Ghi chú sử dụng

Điểm cần nhớ

  • Nghĩa: quy tắc bộ quy — "a code of conduct/ethics" (bộ quy tắc ứng xử/đạo đức — cụm doanh nghiệp), "the penal code" (bộ luật hình sự), "dress code".
  • Nghĩa tín hiệu/mã — "area code", "barcode", "enter the code"; lập trình: "write code" (viết mã).
  • "codify" (động từ — hệ thống hóa thành điều luật) — "codified rules".

Dễ nhầm

  • "code" (bộ quy tắc) ≠ "code" (mã số) — hai nghĩa sống song song, ngữ cảnh quyết định: "Enter your code" vs "a strict dress code".
  • "code of conduct" KHÔNG số nhiều trừ khi nhiều bộ khác nhau: "codes of conduct across industries".
  • "encode/decode" (mã hóa/giải mã) — động từ kỹ thuật cùng họ.

Mẫu câu giá trị

  • "All staff sign the code of conduct annually." (mọi nhân viên ký bộ quy tắc ứng xử hằng năm).
  • "The building's fire code requires two exits." (quy chuẩn phòng cháy của tòa nhà đòi hai lối thoát).
  • "She writes code for a living." (cô viết mã phần mềm để kiếm sống).
