Ghi chú sử dụng

Điểm cần nhớ

  • table = bàn / bảng số liệu: "the table below shows..." (bảng dưới đây cho thấy — Task 1 viết bảng!).
  • timetable = thời khóa biểu; table (v, họp hành) = đưa ra bàn bạc: "table a proposal".

Dễ nhầm

  • at the table (ngồi bên bàn làm việc/ăn) — khẩu cảnh quyết định nghĩa.

Mẫu câu giá trị

  • "The table below compares three providers." (bảng dưới so sánh ba nhà cung cấp).
  • "Everyone gathered around the table." (mọi người quây quần bên bàn).
