# Learner reuse protocol — approximately 72-hour early-retention signal

Honest framing: this measures **early retention after a 3-day delay**, NOT the full
7-day protocol (`docs/learner-reuse-protocol-7day.md`, retained as follow-up research).
A same-day test cannot establish delayed retention. Schedule the follow-up about 72 hours after each person’s Day 0 and record both timestamps. Example: 31 Oct → 3 Nov; 30 Oct → 2 Nov. Repository participant execution/results remain unverified; this is a protocol, not a result.

## Sample
- n = 5–10 Vietnamese adult learners, intermediate English (B1–B2 self-report).
- Convenience sample (friends/colleagues). NOT randomized, NOT a control group.
- Record: n, level, dropout count. Report all of them, including dropouts.

## Phrase set (6 items, taught Day 0 via the app loop)
1. `take off` — cất cánh (Our flight took off late…)
2. `take off` — cởi ra (take your boots off…)
3. `take time off` — nghỉ làm (taking Friday off…)
4. `take off` — trở nên phổ biến (her career took off…)
5. `take into account` — tính đến, cân nhắc
6. `take turns` — lần lượt, thay phiên

## Procedure
- **Day 0 (record the actual date/time for each person):** each learner runs the hero loop in the app for the 6 items
  (read → phrase in context → new-situation answer → quoted feedback → Vault).
  Log which items each learner saved. No further study allowed afterwards.
- **Follow-up (about 72 hours after that person’s Day 0):** surprise reuse task, no review permitted. For each item, give a
  NEW situation in Vietnamese; learner must produce the English phrase in a full
  sentence, unaided. Use situations that genuinely change the role, audience or purpose from teaching; avoid merely retranslating the same source sentence.
- Collect answers as text/screenshots with timestamps.

## Scoring rubric (per item, per learner)
- **2 = correct:** right phrase + grammatical sentence fitting the situation.
- **1 = partial:** intended target meaning and relevant situation are clear, but form/grammar is not fully acceptable.
- **0 = wrong/missing:** wrong phrase/sense, irrelevant response, or no answer. Record missing/dropout data separately; do not silently discard it.
- Score blind if possible (a second person scores without knowing Day-0 logs).

## Reporting (3 Nov)
- Table: learner × item scores, mean per item, mean overall. Primary correct-reuse rate = items scored 2 / all scheduled item opportunities for completed follow-ups; name this denominator. Report score-1 partial reuse separately, plus n recruited/completed, dropout and missing counts. Do not call a score ≥1 fully correct reuse.
- State plainly: n, no control group, 3-day (not 7-day) delay, convenience sample.
- Claim allowed: "X% of taught phrases were reused correctly after 3 days (n=…)".
- Claim NOT allowed: learning efficacy, superiority over any method, generalization.

## Limits (must appear in any submission)
- Small convenience sample; no control; short delay; single rater unless blinded.
- The 7-day protocol is a proposed follow-up plan. Do not call either protocol pre-registered without a timestamped registration record predating data collection.
