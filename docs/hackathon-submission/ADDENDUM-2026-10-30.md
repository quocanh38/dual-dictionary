## Limits carried forward (must appear in any submission)

- AI-assisted cross-model review is not independent human English certification.
- Browser checks are viewport emulation unless a record names a physical device.
- HTTP 200 / valid JSON / schema pass / model agreement do not prove linguistic
  correctness. Coverage % is a frequency-based estimate, not personal knowledge.
- Tutor/IELTS guidance is formative: not official IELTS material, calibrated band
  diagnosis, score guarantee, or proven learning efficacy. Reading passages are
  short-form practice, not full test sections.
- Token ledgers are request evidence, not account-wide billing meters.
