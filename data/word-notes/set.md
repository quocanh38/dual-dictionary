### Điểm cần nhớ
- **set** (set, set — không đổi): đặt/thiết lập: "set a goal", "set an example" (làm gương).
### Dễ nhầm
- be set to + V = sẵn sàng sẽ: "The team is set to launch."
- set up = lập/thành lập: "set up a business"; set off = khởi hành/kích hoạt; set back = làm chậm trễ.
### Mẫu câu giá trị
- "Set **realistic** goals each week." (đặt mục tiêu thực tế).
- "Rising costs **set back** the project by months." (chi phí đội làm chậm dự án).
