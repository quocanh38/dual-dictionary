### Điểm cần nhớ
- host = **người chủ nhà/đón tiếp**: "host a conference/visitor"; "the host city" (thành phố đăng cai).
- **a host OF problems/ideas** = hàng loạt/a lot: "a host of practical issues".
- host (n) — vật chủ (sinh học: "the parasite's host"); hosting (chạy server — công nghệ).
### Dễ nhầm
- host (đón tiếp, có chương trình) vs **receive** (tiếp nhận — thư, thông tin) vs **accommodate** (cho trú/chứa).
- "hostile" (đối địch) cùng gốc — nghĩa trái ngược; chớ lẫn "host/hostile".
### Mẫu câu giá trị
- "The region will **host** the robotics fair." (vùng này sẽ đăng cai hội chợ robot).
- "Rising rents create **a host of** new problems." (giá thuê tăng tạo ra hàng loạt vấn đề mới).
