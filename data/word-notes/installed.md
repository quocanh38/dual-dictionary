### Điểm cần nhớ
- installed software; installed a system; install → put in place
### Dễ nhầm
- installed is the past form of install, meaning set up equipment or software so it can be used
### Mẫu câu giá trị
- “They installed new security cameras last week.” (Tuần trước họ đã lắp camera an ninh mới.)
