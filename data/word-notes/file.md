### Điểm cần nhớ
- **file** = hồ sơ/tệp (n) / lưu hồ sơ (v): **save a file** (lưu tệp — máy tính), **file a complaint** = nộp đơn khiếu nại (pháp lý — file = đệ trình chính thức!);
- file = hồ ngăn (file cabinet);
- file (v) = xếp hàng đi một hàng dọc ("file out" — lần lượt đi ra).
### Dễ nhầm
- file (hồ sơ/tệp) vs document (tài liệu văn bản) vs record (hồ sơ ghi nhận lịch sử).
### Mẫu câu giá trị
- "Download the **file** from the link below." (tải tệp qua link dưới đây — câu web chuẩn).
- "The lawyer **filed** the paperwork on time." (luật sư nộp hồ sơ đúng hạn).
