### Điểm cần nhớ
- logical conclusion; logical thinking; logically consistent
### Dễ nhầm
- logical means following clear reasoning; it is not the same as true, since valid reasoning can start from false assumptions
### Mẫu câu giá trị
- “That is a logical explanation for the delay.” (Đó là lời giải thích hợp lý cho sự chậm trễ.)
